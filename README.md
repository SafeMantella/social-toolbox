# social-toolbox

Scripts pequenos de pesquisa e produção de conteúdo.

| pasta | o que faz |
|---|---|
| `keyword-mining` | autocomplete (suggest) pra minerar palavras-chave |
| `minerar-hooks` | CSV de hooks + views → ranking por percentil e famílias de abertura |
| `pdf-to-markdown` | PDF/EPUB → Markdown |
| `grokbot` | envia mensagem pro webhook do bot estrategista (copie `.env.example` pra `.env`) |
| `links` | catálogo de links de ferramentas (`ferramentas.csv`) |
| `extrair-audio` | extrai o áudio de vídeos sem reencodar (ffmpeg); README com os gotchas do Adobe Podcast |
| `grok-imagem` | gera 1 imagem pelo Grok CLI e copia pro destino |

> Feito pro meu projeto de redes sociais (macOS). Os scripts assumem a pasta `ferramentas/` do projeto e alguns têm caminho absoluto `/Volumes/1TB Mac/...`: ajuste antes de usar em outro lugar.
